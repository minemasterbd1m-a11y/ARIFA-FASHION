ARIFA FASHION WEBSITE + ADMIN PANEL

FILES
- index.html: customer-facing fashion storefront
- admin.html: product and store settings dashboard
- assets/arifa-fashion-logo.webp: supplied Arifa Fashion logo

ADMIN
1. Upload the entire folder contents to your static hosting.
2. Open /admin.html to access the dashboard.
3. Demo password: Arifa@123 (change this in admin.html before sharing the site).
4. Add/edit/delete products, upload product photos (max 1.2 MB each), set prices and stock, show/hide items, and save the WhatsApp number with country code (e.g. 8801XXXXXXXXX).
5. Open the storefront in the SAME browser/device to see saved product changes. Use Export Products JSON for a backup.

IMPORTANT LIMITATIONS
This is a front-end starter admin panel. Product/settings data is saved in browser localStorage, so it is not shared between customers/devices and may be cleared by the browser. The demo password is not secure authentication. WhatsApp orders open a prefilled message; orders are not stored in an admin order database. For a real production store with secure login, shared inventory, customer orders and sales reports, connect a backend/database (for example Supabase or Firebase) and server-side authentication.

DESIGN
Responsive warm cream, bronze and gold fashion theme. Collections: 2 Piece, 3 Piece, One Piece, Kurti, Tops, Hijab and Bags.
